Download the required mods from the links below:

[Pry Open and Journal Mods](https://www.mediafire.com/folder/2dzvzd3sez9iv/Zomboid+Mods)

[Vehicle Mods](https://drive.google.com/drive/folders/1Gv9ELkXPmi5H_3W-yUI377Z8hztZXKmP)

## Installation

1. Download the mods from the links.
2. Extract the files.
3. Press `Win + R`.
4. Enter:
   `%UserProfile%\Zomboid\mods`
5. Put the mod folders inside the `mods` folder.
6. Start Project Zomboid and enable the mods.

Make sure everyone uses the same mod list.
